# The Problem

Today, UPSC students study from many different sources:

* NCERT
* Laxmikanth
* Coaching notes
* Newspapers
* Current affairs magazines
* Previous year questions
* YouTube videos

Whenever they revise a topic, they keep switching between all these resources.

For example, if a student wants to revise **Fundamental Rights**, they might have to:

* Re-read dozens of pages from Laxmikanth
* Look up Articles 12–35
* Search for previous year questions
* Rebuild mental maps of exceptions and writs from scratch

Everything is scattered — and aspirants have very little time.

---

# Our Solution

We keep **Laxmikanth chapter order** as the browse spine (familiar for people who already read the book), and teach **concepts** inside each chapter through **visuals**, not another prose dump.

For example:

```
Polity → Ch. 8 Fundamental Rights → Art. 19 cluster
```

Maps, flowcharts, and comparisons first. Detail on hover/click. Notes stay collapsed unless you open them.

---

# What a student sees

When the student opens a **Fundamental Rights** cluster, they see:

* Interactive visual blocks first (mental model / pillars / flowchart / comparison / heatmap)
* Collapsed notes (optional)
* Landmark cases and amendments (where linked)
* Previous year UPSC questions (reference)
* Related concepts
* Soft progress (studied / revise later)

They don't need to re-read the whole chapter to revise the structure.

---

# Learning becomes visual revision

Instead of only reading chapters one after another,

students revise through connected visuals.

For example:

```
Fundamental Rights (shield → pillars)

↓

State (Art. 12) → Equality (14–18) → Freedom (19) → Life (21) → Remedies (32)
```

Each cluster is clickable.

Revision feels like navigating a map, not scrolling a blog.

---

# Visual Learning

Many students understand better when they can **see** how topics are connected.

The platform picks a **visual grammar** that matches the idea (full list in `docs/VISUAL_GRAMMARS.md`):

* **Mental model / shield** — intuition before Articles
* **Tree / pillars** — where FR sits; six categories
* **Timeline** — amendments and evolution
* **Decision / restriction trees** — which Article; reasonable restrictions
* **Journey / simulator** — real-life path; what-if scenarios
* **Comparison / heatmap / case network / memory palace / article explorer**
* **Relationship graph** — parent/related network across concepts

Browse every template at `/concepts/visual-grammar-catalog`. Students click any node or step for the detail panel.
